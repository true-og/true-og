# Plaza

An open source BuildBattle-OG arena map for Purpur 1.19.4: twelve build plots in a ring
around a central plaza, floating in the void. Generated by `gen_plaza.py` (this folder's
`tools/` copy) from the public-domain `Template_World`, so every block here is
[Unlicense](LICENSE.md) / public domain.

## Layout

| Element | Position |
|---|---|
| Plot floors | y = 64, 31 x 31 oak logs, plot cuboid y 64..96 |
| Plot frame | 1-block polished deepslate ring outside the cuboid, sea lantern corners |
| Plaza | 41 x 41 smooth stone at y = 64, centre (0, 64, 0), barrier rail three high |
| Start / spectator spot | `0.5, 65, 0.5` |
| Plot pitch | 44 blocks between centres, 13 blocks of gap |

The plugin regenerates every plot floor from its cuboid's lowest layer using
`Floor.Material` (`log` by default), so the oak floor is what a reset produces too. Frames and
pedestals sit outside the cuboids and survive resets.

## Deploying

1. Copy this folder to the server root as `BB1-map` and `BB1_Hub` as `BB1-hub`, then register
   both with MyWorlds (`/mw load BB1-map`, `/mw load BB1-hub`). The live `worlds.yml` already
   lists both with the `Splegg-OG:void` chunk generator, so ungenerated chunks stay void.
2. Merge `arenas.yml` below into `plugins/BuildBattle-OG/arenas.yml`, run `/bba reload`.
3. Lobby and end locations point at the Green Leave Lobby spawn in `BB1-hub`; move them with
   `/bba setup edit BB1` if the hub changes.

## Regenerating

```
python3 -m venv venv && venv/bin/pip install nbtlib
venv/bin/python tools/gen_plaza.py /path/to/output/Plaza
```

Edit the constants at the top of the script (plot size, pitch, blocks) and rerun; the script
rebuilds the region files from `Template_World` every time.
